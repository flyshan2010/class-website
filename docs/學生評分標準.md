# 🎯 學生學習報告・評分項目與標準（給學生的努力方向）

> 目的：讓每位同學看得懂報告上四個等第（內容評量／作業成績／上課參與／生活常規）
> 是怎麼來的、要怎麼做才會進步。標準全部對齊系統實際計分規則
> （/class-log 記錄 → /class-report 換算），老師答得出「為什麼是這個等第」。

等第一律用五級：**特優 ＞ 優 ＞ 甲 ＞ 乙 ＞ 丙**。
**甲＝基準值**（符合期待、穩定表現；沒有特別紀錄時預設為甲）；乙、丙代表要加油。

> 📏 學習報告頁「等第怎麼看？」區塊（`assets/js/report.js` 的 `GRADE_GUIDE`）摘錄本檔特優／優／甲三級，**改本檔標準時要同步改那裡**。

> 📌 **等第只看「本週」的紀錄**：學生每週表現不同，這週沒有紀錄就是甲（基準），不沿用上週。

## 〇、紀錄怎麼分正向／負向／中性（2026-09-13 定版）

| 分類 | 意思 | 例子 | 會不會影響分數與崑山幣 |
|---|---|---|---|
| ＋ 正向 | 比本分多做一步的主動表現 | **上台做題、上台回答、課堂發表（被老師點名上台也算）**、主動舉手、幫助同學、作業用心或主動訂正；作業清點「完成」 | 會加分、加幣（作業清點「完成」例外：不直接加分，當作業成績的依據，一週結算一次） |
| － 負向 | 違反班規或常規，提醒後還是沒做到 | 依班規；打掃沒達標、潔牙含氟沒做也沒補做 | 班規照規定扣；打掃沒達標、常規沒做到本身不扣分（一週打掃沒達標 3 次以上才扣 5 幣） |
| 中性 | 只是記下事實，不評價 | 請假或用特權沒去打掃／午餐、去支援別組、通知單轉交 | 不影響 |
| 不記 | 守本分 | 專心聽講、被點到能回答、按時交作業 | 就是「甲」 |

## 一、內容評量（平時學習的評量表現）

- **平常週資料來源**：紀錄庫「評量」類紀錄（隨堂小考、聽寫、形成性評量等）
  ＋ 學期成績庫的「平時」分（平時 50% 的部分）。
- **期考週資料來源**：改用學期成績庫三科平均（平時 50% ＋ 期考 50%）。
- **成績組成**：學期成績 ＝ 平時 50%（日常表現 20% ＋ 平時考 10% ＋ 作業 20%）＋ 期考 50%。
- **等第對照（期考週依分數換算）**：

| 等第 | 三科平均 |
|---|---|
| 特優 | 90 分以上 |
| 優 | 80–89 分 |
| 甲 | 70–79 分（基準） |
| 乙 | 60–69 分 |
| 丙 | 60 分以下 |

- **怎麼努力**：平時的每一次小考、聽寫都算數 → 平常認真準備，不必等到期考才衝刺。
  進步分數 ≥ 10 或拿到「進步獎」，會自動寫進報告「學生亮點」並加發 20 崑山幣。

## 二、作業成績

- **資料來源**：紀錄庫「作業」類紀錄（準時／遲交／缺交／訂正／用心）的正負向累積。

| 等第 | 表現 |
|---|---|
| 特優 | 全部準時、內容用心，主動加做或協助同學 |
| 優 | 準時繳交、完整用心，會主動訂正 |
| 甲 | 大致準時完整，偶爾需提醒（基準／無紀錄預設） |
| 乙 | 常需催交、品質普通、少訂正 |
| 丙 | 常缺交或遲交、應付了事、未訂正 |

- **怎麼努力**：聯絡簿記下作業→回家先寫完→睡前檢查書包；被退的作業訂正可加分。

## 三、上課參與

- **資料來源**：紀錄庫「課堂表現」類紀錄，**照「課堂量尺」判**（2026-09-25 起，第 4 週報告起適用；班網「班規」頁可看整把尺）。

| 課堂量尺 | 行為 | 崑山幣 |
|---|---|---|
| +4 帶著全班一起學會 | 全班卡住時提出關鍵想法讓大家都懂；上台帶全班練習 | +15 |
| +3 帶動別人學 | 帶動小組討論讓每個組員都說出想法；上台講解解法，同學聽得懂 | +10 |
| +2 主動參與 | 主動舉手發表；上台做題或回答（被點名上台也算）；分組時主動提出想法 | +5 |
| +1 被動盡本分（義務線） | 遵守上課規則、專心聽課、完成課堂指派任務 | 不記點 |
| −1 影響課堂 | 干擾上課；打斷、嘲笑同學發言（班規⑨⑤） | −5 |
| −2 讓別人沒辦法學 | 提醒兩次後仍繼續吵；科任課不守課堂規則（班規⑨⑤） | −10 |
| −3 嚴重傷害他人 | 重大安全事件、霸凌、性平 | 紅線 |

| 等第 | 條件（只看本週） |
|---|---|
| 特優 | 本週有 +3 以上的課堂紀錄 |
| 優 | 本週有 +2 的課堂紀錄（含舉手回答、小組加分） |
| 甲 | 守住 +1 盡本分：沒有主動參與紀錄、也沒有課堂負向（基準／無紀錄預設） |
| 有課堂負向時 | 往下降一級（特優→優、優→甲），最低降到甲；「小組扣分」不算個人負向 |
| 乙 | 課堂負向程度1 達 5 次以上，或程度2 有 1 次 |
| 丙 | 課堂負向程度2 達 3 次以上，或程度3 有 1 次 |

- 課後「教同學功課」算品格量尺的幫助他人（人際互動），不算課堂量尺。

- **怎麼努力**：每節至少舉手一次、分組時負責一個小任務、有疑問就發問。

## 四、生活常規

- **資料來源**：紀錄庫「生活指導」＋「生活技能」類紀錄（秩序、整潔、物品管理、
  值日打掃、自理）的正負向累積。

| 等第 | 表現 |
|---|---|
| 特優 | 常規優良、主動維護環境，能提醒帶動同學 |
| 優 | 整潔守規、打掃值日盡責 |
| 甲 | 常規平穩、無特別事件（基準／無紀錄預設） |
| 乙 | 偶爾違規、東西亂放，需提醒 |
| 丙 | 常違反班規、打掃隨便，需反覆提醒 |

- **怎麼努力**：下課先收桌面、排隊安靜、輪到值日認真做完再走。
- **提醒（2026-09-18 起）**：**上學遲到、午餐後潔牙沒補做**這兩類，老師仍會照實記在報告的「生活技能狀態」裡，也會反映在分數上，但**不會單獨把等第打成「乙」**——這類是可以慢慢練起來的生活習慣，不是重大違規。看到報告裡有這些紀錄、等第卻是「甲」，是正常的。
- **提醒**：負向紀錄除了扣崑山幣，還會對應「同領域代價」
  （例如：弄亂→自己整理好；打掃沒做完→補做），做到即可修復。

## 五、五向度雷達圖（國語／數學／社會／人際互動／生活技能）

- 每個向度從 **3 分（中間值）** 起算，滿分 5。
- 每一則紀錄依公式加減：**正負向（＋/－）× 程度（1–3）× 0.5**。
  例：一則「＋2」的紀錄 → +1.0 分；一則「−1」→ −0.5 分；中性不計。
- 該週該向度沒有任何紀錄 → 沿用上週分數（沒有上週 → 3 分）。
- 對照：國／數／社 ← 該科課堂表現紀錄（作業只看「作業成績」等第、評量只看「內容評量」等第，不重複計分）；人際互動 ← 人際紀錄；
  生活技能 ← 生活技能＋生活指導紀錄。

**一句話**：想讓雷達圖變大，就是平時多累積「正向、程度高」的好表現紀錄。

## 六、金幣（崑山幣）連動

- 每一則正負向紀錄自動換算金幣：**金幣 ＝ ±1 × 程度 × 5**（亮點類同一條，2026-09-06 起）。
- 每週五「週結」統一入帳：發薪（職務週薪）→ 結算獎懲 → 進步獎 → 工作薪水（打掃 次數×2、午餐 次數×2、班級常規獎勵 天數×1＋全勤3）。
  ※2026-08-14 起利息停用（詳見 `班級銀行制度設計.md` §四）。
- 所以「上課參與／作業／生活常規／內容評量」表現好，不只等第漂亮，錢包也會變厚。

> 本標準由班級系統自動計分，老師僅微調；每學期可依班級狀況調整級距。
