### 課堂量尺判級（課堂類寫行為、不寫數字）
課堂表現類的**正向**紀錄，程度由下表關鍵詞決定（量尺比程度多一級「+1 盡本分」，量尺級數和程度差 1，所以課堂正向不看數字）：

| 程度（量尺） | 關鍵詞 |
|---|---|
| 1（+2 主動參與） | 舉手、發表、主動回答、上台做題、上台寫、上台回答、提出想法、主動畫重點、表現良好、認真配合（全班一起記的「全班表現良好」也算） |
| 2（+3 帶動別人） | 帶動討論、帶動小組、帶小組、講解給同學、教會組員、上台講解 |
| 3（+4 帶全班） | 帶全班、帶大家練習、讓全班都懂 |

- 同句命中多級取最高級（「上台講解讓全班都懂」→ 3）。
- **判不出是哪一級 → 不寫入**，狀態=失敗＋E03，錯誤訊息「課堂表現判不出量尺級數，請寫出行為（例：座號5 數學課帶動小組討論）」。**不得預設程度 1**。
- **課堂正向句不看數字**：句中若附了數字（「+2」）或「N 點／幣」，一律不採用，程度與金幣只照關鍵詞判定，執行紀錄註明「已依行為判級，未採用句中數字」。
- 課堂**負向**與其他類別照舊：數字＝程度＝品格量尺級數。

### ⚠️ 鐵則：程度 1–3，「N 點」是金額不是程度（E05）
例：「…有繳交作業+10點」若被解析成程度 10，套公式 ×5 會變成每人 +50 幣（原意是 +10），而且不會報錯。因此：
1. 數字後面接**「點」「幣」「崑山幣」「元」→ 那是金額**：金幣影響直接填該數，**程度由金額回推**＝|金額|÷5（**亮點類同樣 ÷5**），落在 1–3 才寫入。例：「+10點」→ 金幣影響 10、程度 2；「-5點」→ 金幣影響 -5、程度 1。（課堂表現類正向紀錄例外，見上方量尺判級。）
2. 數字**沒有單位**（「+1」「-2」）→ 那是程度，金幣影響照公式算。
3. **程度只接受 1、2、3**。回推或解析出 0、>3、非整數 → **不寫入**，狀態=失敗＋**E05**，錯誤訊息「這句的點數換算不出 1–3 的程度，請確認要記幾點」。**定額項目除外**（直接填金幣影響、不算程度）：個人參賽獲獎 +20／+40／+80、布可星球每 10 本 +20、**重大安全事件／霸凌／性平 −200**。
4. 一次交辦影響多人時，**先算一個人的金額寫進執行紀錄**再批次寫。
5. **班級榮譽競賽得獎（團體）**：生活榮譽競賽、班級學藝比賽、班級體育比賽等**班級層級**獎項
   → ① 全班每位在學學生各一則：類別＝亮點、**程度 2**、金幣影響 **+10**；
     ② **主責幹部組再各一則**：類別＝亮點、**程度 3**、金幣影響 **+15**
        （**不分名次一律 +15**——這是影響全班的良好行為，給到量尺最高級）。
        事由寫「榮譽競賽○○獎—○○組額外獎金」，**與①分開兩則，不合併**；
        組別對應：**秩序獎 → 班級領導組**／**整潔獎 → 生活與衛生組**，查 about.json 的 `cadres[].group`；
        獎項名稱對不到組別 → **停待審請老師指定**，不得自行猜。

### 群體詞展開
一段多則（每行或分號隔開）各成一則。群體詞一律照下表機械展開：
- 「全班／大家」→ 每位在學學生（27 人）
- 「全班男生／男生／男同學」→ 名冊性別=男（座號 1–15，15 人）
- 「全班女生／女生／女同學」→ 名冊性別=女（座號 16–27，12 人）
- 「幹部」→ 名冊「職務」非空者；**「○○組」→ about.json `cadres[].group` 等於該組名的職務，再由名冊職務反查座號**
- 「座號3、7、12」列舉 → 指定座號
- **「座號1-7、9-25」區間 → `N-M`／`N~M`／`N–M`（半形／全形連字號、波浪號都吃）＝座號 N 到 M **含兩端**逐號展開，可與列舉混用。護欄三條：① `N > M` → E03 失敗，**不自動對調**；② 展開後逐號比對在學名冊，**不在學的自動略過**並在執行紀錄註明；③ 展開後 0 人 → E03。**區間只展開座號**。**
