### 日課表怎麼改
在 Notion「**🕐 日課表**」資料庫改，一列就是一節課（星期＋節次＋科目＋教師＋教室）：
- **換科目／改老師名字／改教室**：直接改那一列的欄位。
- **調課**：改「星期」或「節次」即可。
- **停開某節**：取消勾「顯示」（或刪除該列），該格就會變空白。
- 晨掃、早自修、朝會、午休與週三／週五半天等固定時段由網站自動產生，不用建。
- 節次時間、科目底色與下方說明文字寫在 `scripts/sync-notion.mjs` 的 `SCHEDULE_META`，要改再進 repo。
改完等自動同步（07/16/20 時）或到 Actions 手動 Run workflow 立即生效。

### 學生系統怎麼用（2026-07 全面改版：一句話記錄 → 週報告全自動）

**學生基本資料只設定一次**（名冊：姓名/座號/查詢碼/頭貼/職務/週薪），之後平時只做一件事——
在 Claude Code 用一句話記錄，其餘全自動、報告筆筆有據：

> 🧑‍⚕️ **學生 360°（ClassCare，2026-07-25 新增）**：名冊多了「支持需求與策略／健康行政備註／轉入交接摘要」
> 三欄，並有「🧑‍⚕️ 學生360°（ClassCare）」檢視分頁——接班、轉入生報到、想記某生的有效策略時用它；
> 點開任一學生頁可看該生紀錄／成績／銀行／報告／輔導全部關聯。這四欄（含家長聯絡備註）屬高敏個資，
> **永不同步班網、永不進 NotebookLM**（同步程式已內建防漏護欄，外洩會直接讓同步失敗）。

| 時機 | 你說一句話 | 系統做的事 |
|---|---|---|
| 平時隨手（10 秒） | 「座號5 數學小考粗心 -1」「記錄：…」 | 寫入紀錄庫（類別/科目/正負向/程度/金幣自動判） |
| 通知類事項 | 「座號16 視力複檢通知已轉交 記一筆」 | 「事務通知」類：不評分不扣幣，只進家長建議 |
| 考完定期評量 | 上傳成績單「匯入成績」 | 寫入 📚 學期成績庫（期考/名次/進步獎；平時＋期考各佔 50% 自動算） |
| 學期中平時成績 | 「登記國語作業成績…」 | 寫入學期成績庫日常/平考/作業欄，公式自動算 |
| 週五放學 | 「class-bank 週結」 | 發薪（照名冊職務）→ 獎懲入帳（照紀錄庫金幣）→ 利息 |
| 週末 | 「產生本週學習報告」 | 全班報告草稿：五向度、等第、亮點、建議**全部引用當週紀錄**，並附「依據紀錄數」 |
| 需要介入時 | 「幫座號N開學習/生活輔導」 | 開輔導個案：困難點（附事證）→可檢核目標→代價設計輔導行為；報告會自動提示候選名單 |
| 課堂當下即時操作 | 開「班級管理工作台」（班網常用網站＞班級事務） | 黑板/加分/分組/考試計時；**不建真實姓名名單**，值得留存的表現回來仍用一句話記錄 |

報告檢查重點：
1. 「學生」欄只填**姓名**（不加座號）；查詢碼與頭貼從名冊自動帶，報告列不用填。
2. 每列有「**依據紀錄數**」——0 或 1 代表該週幾乎沒觀察紀錄，AI 會提醒「連續兩週空白名單」。
3. **期中考、期末考當週**的報告自動加「📝 考試成績摘要」：孩子各科成績、班平均、名次＋全班級距表。
   **考週不是特殊週**：五向度分數與行為觀察照常由當週紀錄生成（考週也照常用一句話記錄），
   成績摘要只是額外附加，不會取代行為向度。
4. 檢查微調 → 勾「**發布**」→ 家長到班網「📊 學習報告」輸入**座號＋查詢碼**查看；多週自動變成週次切換。

開學、期中考、期末考、休業式等重要日程**自動從班網 Google 行事曆讀取**（週次由此推算），
換學期不用改設定；行事曆沒排到時才退回 Notion「⚙️ 網站設定」的學期設定列。

家長端功能：**🖨️ 列印報告**（一張 A4 直式）、**🕶️ 去識別化**（姓名變「王○明」、座號與頭貼隱藏，適合列印留存或展示）。

🔒 隱私設計：報告與頭貼在同步時就用該生查詢碼**加密**，班網上沒有明文；查詢碼每位學生不同，私下發給該家長；沒發布的列完全不會上傳。

### 班規五層與「常規不扣幣」（2026-08-08 改版，記錄時會用到）

班規五層，環環相扣：**四大理念**（注意安全／尊重他人／主動關懷／認真負責）→
**公約五行動**（往哪走）→ **8 大班規**（什麼可以不可以，**每條掛在一條公約下**）→
**生活常規 routine**（怎麼做）→ **獎懲輔導**。
公約、8 大班規與生活常規（一日作息＋課堂五流程）的設計說明都在 Notion「📜 班規制度說明（五層架構・獎懲・常規）」頁（2026-08-09 由原「📜 班級獎懲規定」＋「📋 班級公約與一日常規」兩頁合併）。

**公約 → 班規對照**（2026-08-08 起；原本班規是掛在理念下，中間隔一層，現在直接掛公約）：

| 公約 | 班規 |
|---|---|
| 1 說話有禮貌，也有分寸 | ② 待人有禮貌 |
| 2 想法不一樣，也能好好相處 | ⑤ 上課守秩序 |
| 3 看見需要，主動幫忙 | ⑧ 口說好話 |
| 4 照顧自己，也照顧別人的安全 | ⑥ 走廊（教室）不奔跑 |
| 5 答應的事，努力完成 | ① 上學（課）不遲到　③ 打掃要認真　④ 作業要用心　⑦ 管好自己 |

這張表班網「🌈 關於我們 →🤝 班級公約」分頁也看得到（含每條的加扣幣與改正方式），
可以直接投影出來跟學生對。公約與班規的文字、崑山幣金額都沒有變，只是層級歸屬變清楚。

**⚠️ 當天第一次改過不扣點（2026-08-08 新增，記錄時直接影響金幣）**：同一天、同一項不當行為，
**第一次只要照「改正方式」做到就不扣點**；同一天再犯同一行為，才既要改過、也照偏差表扣點。
`/class-log` 記錄時第一次已改過就把**金幣影響填 0（中性）**，但**行為仍要記一筆**——
不記就追蹤不到同一天的第二次，也算不進「兩週同類負向 ≥3 開輔導個案」。

**🚨 重大安全事件、霸凌、性平**（2026-08-08 自偏差表移出、單獨列一區）：**依校內相關防治準則流程處理**，
依規定通報、調查、輔導，需要時再開 /class-counsel 個案；**崑山幣扣 −200**（2026-08-08 老師裁示；**定額，不走「程度×5」公式**，/class-log 記錄時金幣影響直接填 −200，比照固定獎勵表；扣到 0 為止仍適用，等於存款一次歸零）。
班網班規區塊也獨立成一張紅卡，處理方式與扣點都寫在上面。

其餘同日調整：學生端一律稱「**改正方式**」（不再用「同領域代價」這種老師術語）；偏差表原「共同」兩條
改標「**上課時間**」；奔跑追逐統一為「**靜坐反省 5 分鐘＋向被撞到、嚇到的人道歉**」（📜 頁兩張表已對齊）。

> ⚠️ **記錄時最重要的一條：常規（routine）沒做到 → 只重做練習，不加扣崑山幣。**
> 判斷句：「他是**不會**，還是**不做**？」
> - **不會**（流程還沒熟，如忘了發材料要先檢查齊全）→ 帶他重做一次，`/class-log` 記錄時
>   **金幣影響填 0（中性）**，或乾脆不記；不套程度公式。
> - **不做**（已經會了卻選擇不做，踩到 8 大班規／公約，如作業缺交、推人、屢勸不聽）→
>   照 📜 頁扣幣表處理，扣的是**班規那一條**，不是常規本身。

課堂五流程（每天反覆用，開學前兩週要帶著練）：① 進教室 ② 發材料 ③ 發言 ④ 小組討論 ⑤ 收拾。
「早晨到校」走入班三步驟（含交作業），「其餘時段回教室」走 ① 進教室流程。

2026-07-27 公約也改了兩處：舊 2＋舊 4 合併為新 2「想法不一樣，也能好好相處」，

### 學生輔導個案怎麼用（🧭 學生輔導紀錄，/class-counsel）

一列＝一個個案，分兩種：**學習輔導**（各科學習困難）與**生活輔導**（偏差態度行為）。
輔導內容屬高敏個資，**永遠不會同步到班網**，只留在 Notion。

**什麼時候開個案**：每週產生學習報告時，AI 會自動偵測並提示「建議開輔導個案名單」
（任一科學期成績 <70／進步分數 ≤−10／兩週內同類負向紀錄 ≥3 筆／程度 3 重大事件）；
你確認後說「**幫座號N開數學學習輔導**」才開案，不會自動開。

**個案內容三要素**（AI 草擬、你確認；2026-07-24 起輔導庫採 ABC 行為觀察格式）：
1. **行為觀察（ABC）**：B-行為（先兆與脈絡）必附事證——學習輔導自動掛「來源成績」、生活輔導掛「來源紀錄」relation，不開空案。
   生活輔導另填 A-背景因素（遠因）、A-立即前事（時間/地點/情境/事件）、C-後果（既有處置）、R-處置後反應，
   AI 據此下「**功能假設**」（逃避／獲得注意／獲得實物或活動／獲得感官刺激；證據不足＝待觀察，先觀察一週），
   功能假設決定輔導行為的設計邊界（例：逃避型行為不可用隔離處理，會正中下懷）。
2. **具體目標**：可檢核、有期限（如「期末數學學期成績達 70 以上」），拒絕「變得更好」這類空話。
3. **輔導行為**：依「代價設計 v3」三段式——【採取措施】＋【對孩子說的話】＋【備註/升級條件】，
   行為與後果真實因果連結（自然後果＞補償型＞限制型），孩子能自己說出「我做了什麼，所以我必須＿＿」才算設計成功。

**檢核與結案**：說「**輔導檢核**」→ AI 對照新成績/新紀錄檢查目標，
達標→「已達標」（成效評估寫具體數據與有效做法）；部分改善→「持續觀察」；
升級為對抗型→建議轉介輔導室雙軌。在名冊點開該生頁面可看到其所有個案歷程（🧭 輔導 relation）。

### 商店兌換申請怎麼處理（🛒 小小銀行「能看也能買」，2026-07-18 上線）

學生在班網「🏦 小小銀行」打開存摺後，買得起又有庫存的商品會出現「🛒 我要兌換」。
（**2026-07-26 起商店只賣特權／活動券，可愛小物已全面下架**；要恢復就到 Notion
「🏪 班級商店」把該品項重新勾「上架」，班網下次同步就會出現，不必改程式。）
按下只是**送出申請，不會扣款**——扣不扣、什麼時候扣，都由你決定：

1. 打開班網「**🧑‍🏫 教師專區**」（頁尾入口）→「🛒 兌換申請」區塊會列出待處理申請。
2. **✅ 核可**：系統自動幫你——帳本記一筆「消費」扣崑山幣 → 商店庫存 −1 → 申請標「已完成」。
   餘額不足會先警示（可選擇強制核可，餘額變負數）。
3. **❌ 駁回**：填一句原因（例：先完成本週任務），不扣款；孩子下次登入存摺看得到。
4. 處理完按「**⚡ 立即更新班網**」，孩子的存摺與商店庫存才會更新到站上。
5. **購買明細**：同區塊「📜 購買明細」看最近 50 筆；完整搜尋開 Notion「🛒 兌換申請」
   （誰、買什麼、多少幣、何時申請／處理、狀態、備註，永久保留）。

防呆設計：每人同時最多 3 筆待處理申請；價格以 Notion 商店為準（改前端騙不了）；
申請要座號＋查詢碼驗證，別班孩子或路人無法亂送。

⚙️ **啟用前提（一次設定）**：Apps Script 代理需更新到 v2.2——開 script.google.com
→ 原代理專案 → 貼上 repo `scripts/apps-script-proxy-v2.gs` 全部內容 → 部署「新版本」（網址不變）。
並確認 Notion integration 能存取 👥 名冊、🏦 帳本、🏪 商店、🛒 兌換申請 四個資料庫
（最簡單：把「🏫 班級經營中心」整頁分享給 integration）。

### 特權券怎麼執行（🎟️ 教師專區「特權執行」，2026-08-01 上線）

孩子兌換到的是**特權券**（免打掃一次券、自由閱讀券…），核可當下就發到他手上，
真正「用掉」是後來的事——這個區塊就是拿來扣次數、避免同一張券被用兩次的。

1. 教師專區 →「**🎟️ 特權執行**」→ 預設是「🎟️ 持有中」，**依座號分組**列出全班還能用的券
   （標題列會顯示「N 位同學持有 M 張券、共 K 次可用」）。找特定學生就在「座號篩選」打座號。
2. 孩子來說「我要用免打掃券」→ 對照清單確認他真的有 → 按「**✅ 使用一次**」
   → 剩餘次數 −1、自動記一筆使用紀錄；次數歸零的券會自動移出清單（跑到「📜 使用歷史」）。
3. **同一天同一張券再按第二次會先跳提醒**（防手滑重複扣），確定要扣才會過。
4. 按錯了：按「**↩️ 撤銷**」把次數加回去（歷史清單裡也找得到，可救回誤扣的最後一次）。
5. 不給用了：按「**🚫 作廢**」填原因（例：學期末結清、條件未達成），剩餘次數歸零。
   **作廢不退幣**——這是刻意的：券是買斷的，退幣會讓孩子學到「反正可以反悔」。
6. **這個區塊即時生效**（正本在 Notion），但孩子存摺上看到的特權要等你按「⚡ 立即更新班網」才同步。

一張券可以用幾次，由 Notion「🏪 班級商店」的「**使用次數**」欄決定（**空白＝1 次**）；

### 作文批改怎麼用（✍️ 教師專區「批改作文」，2026-08-02 上線）

把學生的作文交給系統批改，產出一份「作文批改報告」，**你檢查過、勾了「發布」，

**怎麼送件（2026-08-02 起：不必打座號、可以一次送一疊）**
1. 教師專區按「✍️ 批改作文」→ 句子就是「批改作文」四個字，**不用填座號**。
2. **附上作文照片或掃描 PDF，一次多份也可以**；也能直接把打好的文字貼在後面。
3. 想指定文體（書信、詩歌、讀書報告…）就在句子裡寫明，不寫系統會自己從題目判斷。

   （多篇時自動附全班等第分布與常見錯誤 TOP 10）。

> 你的動作只有兩個：**送出** ＋ 說一句「批改作文」。
> 為什麼不讓排程自動批？因為評分是教學專業判斷，一定要留你把關的那一步；
> 而且雲端排程讀不到本機的批改引擎，硬做會讓評分品質下降。

**座號怎麼來的？（重要）**
系統會讀稿紙抬頭的「班級／座號／姓名」再跟名冊比對，分三種結果：

| 情況 | 系統怎麼做 |
|---|---|
| 座號和姓名都對得上同一人 | ✅ 直接批改 |
| 只讀到其中一項、名冊唯一命中 | ⚠️ 照批，但會列在「已推定身分」請你掃一眼 |
| 兩者互相矛盾／名冊查無／都看不清楚 | ⛔ **這篇先不批**，列在「待確認」，你告訴它座號再跑一次 |

> 這道防呆是有原因的：第一次真實測試那篇，稿紙上寫座號 1，署名卻不是名冊座號 1 的學生。
> 沒有這道檢查，報告就會掛到錯的孩子身上。**寧可它問你，也不要它猜。**

**批改完你會拿到什麼**

- 一份 PDF 存在雲端硬碟 `班級事務/作文批改報告/{學年}/`，可直接列印發回去。
- 一份「**辨識不確定處**」清單——手寫看不清楚的地方會列出來，請對照原稿再改。

**發布給學生看**
1. 到那一列把內容看過、需要就自己改字（AI 寫的評語你有最終決定權）。
2. 勾「**發布**」→ 回教師專區按「一鍵更新班網」。
3. 學生／家長用**座號＋查詢碼**進學習報告，會看到一個「✍️ 我最難忘的一件事」這樣的分頁。

**注意**

### 班級工作台的加分要進報告（🖥️ 工作台回流，2026-07-19 建置｜⏳ 待開學實資料驗證）

課堂上用「班級工作台」（CLASSROOM HUB）按的加分、代幣、出勤、作業狀態，
可以整批倒進紀錄庫，不必再手動補記。做法：

1. 工作台 →「設定」→「**匯出本機資料**」，會下載一個 `.json` 檔。
2. 把檔案丟給 Claude Code，說「**工作台回流**」。
3. AI 列出**待審清單**（只出座號，不出姓名），例如
   「2026-07-18 座號3 發表很有想法 +3〔工作台代幣 +3 → 崑山幣 +15〕」。
4. 你看過、確認沒問題 → AI 才寫進紀錄庫；不確認就不會寫。

**幾個要知道的**
- **不會重複計算**：同一筆加分回流過就不會再出現，可以放心每週匯出一次。
- **代幣就是崑山幣**（2026-07-19 起）：工作台按幾點就是幾點，**1 代幣＝程度 1＝5 崑山幣**。
  你在工作台按 +3，紀錄庫就記程度 3，銀行入帳 +15 崑山幣，尺度和你平常手動記的獎懲金一致。
  清單每筆都會直接標出換算後的崑山幣，覺得某筆該多給或少給，在待審階段直接跟 AI 說。
- **只同步行為獎懲**：薪水、利息、商店消費只存在班級銀行，不會倒回工作台；
  所以**兩邊餘額本來就不一樣**（工作台＝行為點數、銀行＝總資產），不必對帳。
- **只回流「有事的」**：正常出席、作業已完成不會記錄，避免洗版；
  只有遲到／缺席／請假、未繳交／待訂正才進清單。
- **座號會自動雙重核對**：工作台的座號和學生姓名，會拿去跟名冊對照表比對**兩次**。
  兩邊都對得上才直接採用；若座號對得上但姓名對不上（例如名冊換過座號、有轉學生、
  或不小心匯出到別班），該筆會標「**座號待確認**」並寫明原因，請你確認後再入庫；
  兩邊都對不上的學生，整個跳過不入清單，不會亂猜。
  → 平常一切正常時你不會看到任何警告；**一看到警告就代表名冊真的該更新了**。

> ⏳ 目前狀態：所有邏輯已用測試檔驗證通過（含全班 27 人與三種異常情境）。
> 唯一還沒做的是拿你的**真實匯出檔**跑一次，確認欄位名稱與程式預期一致。
> 開學第一次使用時跑一次即可，若有落差 AI 會直接報錯而不會寫錯資料。

     - **文字太長會自動縮字**（下限 11px）保證不爆框，但字會變小；**每欄控制在 2～3 行內最好看**。
     - 電腦／平板是 16:9 海報等比縮放；**手機（≤719px）自動改成上下堆疊可讀版**，箱體順序與配色不變。
2. 狀態改為「**待產文案**」。
3. 打開 Claude Code 說「**幫我產生本週週報三端文案**」→ AI 會把「班網版／LINE版／FB版」寫回 Notion。
4. 檢查文案 → 複製 LINE 版貼班群、FB 版貼社團 → 勾「LINE已發」「FB已發」。
5. 狀態改「**已發布**」→ 班網週報頁自動出現完整版。

## 五、初次設定（只做一次）

### 1. 建 Notion integration（讓 GitHub 能讀資料）
1. 到 https://www.notion.so/my-integrations → 「New integration」。
2. 名稱填 `class-website-sync`，Workspace 選自己的，Capabilities 只需 **Read content**。
3. 複製 **Internal Integration Secret**（`ntn_` 開頭）。
4. 回到 Notion「🏫 班級經營中心」頁面 → 右上「…」→「Connections」→ 加入 `class-website-sync`。

### 2. 建 Google Drive API key（相簿用，可先跳過）
1. https://console.cloud.google.com/ → 建專案 → 啟用「Google Drive API」。
2. 「憑證」→ 建立 API 金鑰 →（建議）限制只能呼叫 Drive API。

### 3. 把金鑰放進 GitHub
GitHub repo → Settings → Secrets and variables → Actions → New repository secret：
- `NOTION_TOKEN` = Notion integration secret
- `DRIVE_API_KEY` = Drive API 金鑰（沒有也能跑，只是相簿沒縮圖）

### 4. 修改班級基本資料
校名、班級、學年度、班級口號、「關於我們」都在 Notion「⚙️ 網站設定與關於我們」維護。
日課表在 Notion「🕐 日課表」資料庫維護。Google 日曆嵌入網址、選單項目與模組顏色在 `data/site-config.json`（技術設定，一般不用動）。

## 六、學期回顧頁

班網的「🎓 學期回顧」頁**全自動**：把已發布的週報（亮點、活動、照片）與相簿彙整成統計數字＋亮點牆＋活動剪影＋每週足跡，不用維護，期末打開就是現成的班級成果展。

2026-07-25 起另有兩個自動區塊（Phase C）：

- **💰 班級經濟大事記**：銀行帳本依週聚合（發薪／獎勵／扣款／利息／消費筆數），只有全班總數、無個人資料；帳本有交易就自動出現。
- **🧠 全班 SEL 成長雷達**：全班 SEL 五能力平均的雷達圖（虛線＝學期初、實線＝最近一週）。
  為避免平均值回推個人，**該週已發布報告需 ≥5 位才會顯示**；平常照常記錄＋發布報告即可，不用另外做事。

### SEL 觀察（學習報告新區塊）

每週報告多了「🧠 SEL 觀察」：從紀錄庫的生活指導／人際互動／生活技能／亮點紀錄，
依 SEL 五能力（自我覺察・自我管理・社會覺察・人際技巧・負責任決策）自動評分並寫 2–4 句觀察
（先肯定 → 正向引導 → 家庭小行動）。老師只要照常用 /class-log 記錄、審報告時順看這段即可；
記錄時保留「幫助同學」「說出感受」「主動承擔」這類原話，歸類會更準。

### 🃏 ECC 活動卡庫（備課抽卡）

Notion「班級經營中心 → 🃏 ECC 活動卡庫」有 30 張課堂活動卡（拍照說故事、廣播劇、逐格動畫…）。
備課時對 Claude 說「**這課幫我抽活動卡**」或「抽 2 張適合社會課的活動卡」，
會依「創作行為 × 領域」推薦並附國小情境改編建議（改編不是照抄）；採用後卡片「使用次數」自動 +1，讓活動輪替不重複。

### 📝 題庫與組卷（2026-07-26 Phase D 上線）

好題不再用完即丟。Notion「班級經營中心 → 📝 題庫」是跨學年累積的題目資產，**不隨學年封存**。

**三件事，都在 Claude 對話中做**（出卷屬重型工作，排程不自動跑）：

1. **入庫**——出完卷說「**這份卷入庫**」，或丟舊考卷檔案說「**匯入題庫**」，
   系統自動拆題並標好單元／難度／認知層次／迷思概念。
2. **審題（你的工作）**——新題一律進「🗂 待審」，**AI 不會、也不能把題目設成「可用」**。
   你看過覺得可以，才自己把狀態改「可用」；改完它才會被抽進考卷。
3. **出卷**——說「**用題庫出康軒數學四上第七單元的卷**」，系統先從可用題抽，
   **自動跳過最近 90 天用過的題**（避免重複考），數量不夠的部分才現場出新題，
   新題一樣進「待審」等你審。出來的還是原本那六份 docx，版面不變。

**考完登記數據**：說「**登記答對率：第1題 22/29、第2題 25/29…**」，系統算出每題答對率寫回題庫。
線上測驗（Google Forms）另會算鑑別度。施測滿 20 人才會判定品質：
太難（<30%）、太簡單（>95%）或鑑別度低的題會被標成「⚠️ 淘汰候選」，
**但要不要停用一律由你決定**——AI 只標記，不淘汰。

好題會累積在「⭐ 優質題」，下次組卷優先被抽中。
