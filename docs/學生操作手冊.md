### 📋 我們的班規（Rules，2026-08-08 上線）

「🤝 班級公約」分頁的公約海報下面，就是**我們班的班規**——一條班規一張卡，
上面寫著**做到的樣子**（加幾點）和**沒做到怎麼辦**（**改正方式** ＋ 扣幾點）；
每張卡下面有一行小字寫它屬於哪一條公約。

| 班規 | 屬於哪條公約 |
|---|---|
| ① 上學（課）不遲到 | 公約 5 答應的事，努力完成 |
| ② 待人有禮貌 | 公約 1 說話有禮貌，也有分寸 |
| ③ 打掃要認真 | 公約 5 答應的事，努力完成 |
| ④ 作業要用心 | 公約 5 答應的事，努力完成 |
| ⑤ 上課守秩序 | 公約 2 想法不一樣也能相處，受人幫助說謝謝 |
| ⑥ 走廊（教室）不奔跑 | 公約 4 照顧自己，也照顧別人的安全 |
| ⑦ 管好自己（自律） | 公約 5 答應的事，努力完成 |
| ⑧ 口說好話 | 公約 3 看見需要，主動幫忙 |

八條班規**依序 ①～⑧ 各一張卡**，後面還有「**上課時間**」兩條（干擾上課、一直提醒還是繼續干擾）與
「**🚨 重大安全事件**」（重大安全事件、霸凌、性平 → 依校內相關防治準則流程處理，🪙 −200）。

三件要記得的事：
1. **扣到 0 就停**，不會變成負的。
2. **當天同一個不當行為，第一次改過就不扣點**；同一天再犯同一件事，就要改過而且扣點。
3. 另外還有亮點、進步獎、比賽獲獎、布可星球等獎勵，詳見「🏦 小小銀行」。

同一頁最下面是「🎁 連續兩週沒有違規可以抽獎」的 8 個獎項——**獎品就是「🏦 小小銀行」商店裡的特權券**
（班級小主人、午餐音樂點播、午休圖書館、黑板創作、桌遊同樂、午餐優先打菜、免打掃一次、優先借閱新書），
平常可以自己存崑山幣換，連續兩週沒有違規也抽得到。

### 🕗 一日作息與常規（Routines，在「🕗 作息與常規」分頁）

**常規＝「怎麼做」**：每個時段要做什麼（早晨入班、晨掃、晨讀、上課、午餐、午休、放學），
再加上每天都會用到的**上課常規**五個流程（進教室／發材料／發言／小組討論／收拾）。

每一條下面有三行（2026-08-09 起）：
- 第一行＝**步驟**（照著做就對了）
- 綠字**做到的樣子**＝這件事做好是什麼模樣
- 橘字**沒做到 → 重做練習**＝沒做好要怎麼補；上課常規那五條還會標**對應哪一條公約與班規**

> **常規沒做到不扣點**——像進教室、排隊、收拾這些「怎麼做」的流程，沒做好就重做一次練到會就好。
> 這也是它跟「班規」分開放兩頁的原因：**班規是守不守（會加扣點），常規是熟不熟（練到會）**。

### 🪙 工作做到了怎麼算（一項工作 ＝ 一次，在「🧹 工作分配」分頁）

身上有幾項工作就**分開算**：同時有打掃和午餐工作，就是兩條線各自結算。

| 情況 | 會發生什麼 | 崑山幣 |
|---|---|---|
| 當天把自己負責的工作做完、做好 | 工作薪水，週五週結入帳 | **＋2**（每次）|
| 有 1～2 次沒做到 | 補做或重做一次，那幾次沒有薪水 | **不扣** |
| 有 3 次以上沒做到 | 踩到班規③「打掃要認真」・程度 1 | **−5** |
| 做得特別好、被公開表揚 | 亮點・程度 1 | **＋10** |

> 🪙 **算法只有一種：做幾次領幾次**（2026-08-31 起）。打掃、午餐工作每做一次 **2 幣**——
> 卡片標題旁的 🪙 標籤就是。原本另外那條「一週 5 次全到 +5」已取消，不必再記兩種算法。
> 班級常規另計：每天達成 **+1 幣**、五天全達成再 **+3 幣**全勤獎（每週最多 8 幣）。
> 這些都在**週五週結**時一起入帳，存摺才看得到。

沒做到不是先扣錢——**先把它補好**，這才是「認真負責」真正的意思。
反覆不做才會扣崑山幣，而且扣到 0 就停，不會變負的。

## 二、要用「座號＋查詢碼」的（個人區）

查詢碼由老師私下發給每位同學（和家長），**每個人不一樣，請不要告訴別人**。

### 📊 學習報告（家長）
1. 班網「學習報告」→ 輸入**座號**與**查詢碼**→ 解密開啟。
2. 內容：五向度雷達、各科狀態與建議、亮點、目標、家長協助建議；考試週多一張成績級距圖；有作品的週會顯示「🎨 本週作品」。
3. 可按「🖨️ 列印」（一張 A4）或「🕶️ 去識別化」（姓名變 王○明，適合留存展示）。

### ✍️ 作文批改報告（2026-08-02 起）
1. 一樣在「學習報告」裡面——解密後上方的分頁若出現「✍️ 我最難忘的一件事」這種**題目**，
   點下去就是那篇作文的批改報告（其他分頁是每週報告，用「第N週」標示）。
2. 裡面有：題目、文體、總評等第，以及老師的開場、🔍 抓漏任務、📋 版面格式、
   🚀 寫作升級站、🏆 閃亮亮成績單（五個項目的等第與建議）、💬 老師的話，
   最後還有一篇 **✨ 修改範文**——照著範文比對自己原稿，是進步最快的方法。
3. 有些篇會附 PDF 下載連結，可以印出來夾在作文簿裡。
4. 老師檢查並勾「發布」之後才會出現；還沒看到就是老師還在批改或還沒發布。

### 🏦 小小銀行（同學）
1. 班網「小小銀行」→ 輸入**座號**與**查詢碼**→「📖 打開存摺」。
2. 存摺會顯示目前餘額與最近 30 筆交易（薪水、獎勵金、消費…）。
   （「利息」2026-08-14 起停發，以前發過的還是看得到。）
3. **崑山幣會花掉，XP 不會**：XP 記錄你做過多少好事、扛過多少責任，
   買東西、被扣點都不會讓它變少。XP 分兩條：

   | | 是什麼 | 從哪裡來 |
   |---|---|---|
   | 🔵 **責任 XP** | 把自己的本分做穩 | 幹部週薪、打掃薪水（依次數）、午餐工作（依次數）、班級常規獎勵（每天達成 +1，五天全到再 +3） |
   | 🟠 **貢獻 XP** | 額外多做的努力 | 正向行為（品格量尺 +1／+2／+3）、亮點（比賽、布可星球）、定期評量進步獎 |

   兩條加起來就是總 XP，總 XP 決定你的稱號：
   🌱 新芽 → ⭐ 小星星（300）→ 🌟 閃耀之星（700）→ 💫 超新星（1200）→ 🏆 星際隊長（1800）。
   商店「🛡️ 職務公會」那一層要**兩條都到門檻**才解得開——只是每天有來、有做完，
   還不夠；要有額外的付出才行。
   你的 XP 與稱號寫在自己的學習報告裡（只有你和家人看得到，**不會公布排名**）。

### 🛒 我要兌換（同學）——用崑山幣換商店的東西
1. 打開存摺後往下看商店櫥窗：**買得起又有庫存**的商品會出現「🛒 我要兌換」按鈕。
2. 錢不夠的商品會顯示「🪙 還差 N 幣」——那就是你的存錢目標！
3. 按下「我要兌換」→ 確認 → 送出申請。**這時候還不會扣錢**，要等老師確認。
4. 老師核可後才會扣崑山幣（存摺會多一筆「🛍️ 消費」）；如果被駁回，老師會寫原因，錢不會扣。
5. 小提醒：一次最多 3 筆申請在等老師處理；送出前想一想「這是需要還是想要？」

### 🎟️ 我的特權（同學）——看看自己有哪些券、還能用幾次
1. 打開存摺後，存摺下面就是「**🎟️ 我的特權**」，列出你**還能用**的特權券。
2. 每張券會寫「**還可以用 N 次**」和兌換日期；用完的券就不會再出現了。
3. 要使用的時候**找老師**，老師會在教師專區幫你扣一次（不能自己扣）。
4. 老師扣完後，這裡的次數要等班網下次更新才會變；**以老師那邊的紀錄為準**。
5. 用不完會不會浪費？會的，所以兌換前先想好什麼時候用得到。

### 🎯 班級共同目標（同學）——全班一起存一個大東西
> 這一區**平常不會出現**，老師開了才看得到。

1. 有些東西一個人存不到（例如全班一起吃的期末夢幻餐點），那就**全班一起存**。
2. 想參加就跟老師說「**我要捐 N 幣**」，老師會幫你記一筆，進度條就往前一格。
3. 進度條只顯示**全班總共存到多少、幾個人一起出力**，
   **不會寫誰捐了多少**——捐多捐少都是心意，不需要被比較。
   你自己捐了多少，打開存摺就看得到（會是一筆「🛍️ 消費」，事由開頭是「集資」）。
4. **捐款會扣崑山幣，但 XP 一點都不會少。** 你為班上做的事，紀錄永遠留著。
5. 存滿了進度條會變綠色、跳出「🎉 目標達成」，接下來就等老師實現囉！

## 三、注意事項

- 🔒 查詢碼＝你的個人鑰匙，不要外流；忘記了請找老師。
- 存摺與報告內容只給自己和家長看，請勿轉傳截圖。
- 頁面資料每天自動更新三次；老師處理完兌換後也會手動更新，稍等一下再重新整理即可。
