2挑選符合條件的文章

3檢查並微修

順序＝Word 裡的順序。主題會依題目自動判斷（標「🤖 依題目判斷」，可直接改）；題目、內文可直接改成老師批閱後的定稿（只存這台電腦，按「標記已繳交」才寫進 Notion）。
✨ 微修＝只改錯字、標點、贅字、語序讓文章通順，改動不超過 5%（程式把關）：按「✨ 微修」送出 → 對 Claude Code 說「校刊微修」→ 回來按「🔄 讀取微修結果」，紅綠對照後逐篇採用。
