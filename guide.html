📋 我們的班規（Rules，2026-08-08 上線）

「🤝 班級公約」分頁的公約海報下面，就是我們班的班規——一條班規一張卡， 上面寫著做到的樣子（加幾點）和沒做到怎麼辦（改正方式 ＋ 扣幾點）； 每張卡下面有一行小字寫它屬於哪一條公約。

班規屬於哪條公約
① 上學（課）不遲到公約 5 答應的事，努力完成
② 待人有禮貌公約 1 說話有禮貌，也有分寸
③ 打掃要認真公約 5 答應的事，努力完成
④ 作業要用心公約 5 答應的事，努力完成
⑤ 上課守秩序公約 2 想法不一樣也能相處，受人幫助說謝謝
⑥ 走廊（教室）不奔跑公約 4 照顧自己，也照顧別人的安全
⑦ 管好自己（自律）公約 5 答應的事，努力完成
⑧ 口說好話公約 3 看見需要，主動幫忙

八條班規依序 ①～⑧ 各一張卡，後面還有「上課時間」兩條（干擾上課、一直提醒還是繼續干擾）與 「🚨 重大安全事件」（重大安全事件、霸凌、性平 → 依校內相關防治準則流程處理，🪙 −200）。

三件要記得的事：

  1. 扣到 0 就停，不會變成負的。
  2. 當天同一個不當行為，第一次改過就不扣點；同一天再犯同一件事，就要改過而且扣點。
  3. 另外還有亮點、進步獎、比賽獲獎、布可星球等獎勵，詳見「🏦 小小銀行」。
  4. 進步獎怎麼拿到：比上一次定期評量的國數社平均進步，就有機會拿到 +5 幣。 要進步幾分看你上一次的平均：95 分以上進步 1 分、85～94 分進步 1 分、 70～84 分進步 3 分、未滿 70 分進步 5 分。分數越高的人門檻越低，因為能進步的空間比較小。 沒拿到進步獎也沒關係，只要有進步，老師都會寫進你的學習報告。

同一頁最下面是「🎁 連續兩週沒有違規可以抽獎」的 8 個獎項——獎品就是「🏦 小小銀行」商店裡的特權券 （班級小主人、午餐音樂點播、午休圖書館、黑板創作、桌遊同樂、午餐優先打菜、免打掃一次、優先借閱新書）， 平常可以自己存崑山幣換，連續兩週沒有違規也抽得到。

🕗 一日作息與常規（Routines，在「🕗 作息與常規」分頁）

常規＝「怎麼做」：每個時段要做什麼（早晨入班、晨掃、晨讀、上課、午餐、午休、放學）， 再加上每天都會用到的上課常規五個流程（進教室／發材料／發言／小組討論／收拾）。

每一條下面有三行（2026-08-09 起）：

  • 第一行＝步驟（照著做就對了）
  • 綠字做到的樣子＝這件事做好是什麼模樣
  • 橘字沒做到 → 重做練習＝沒做好要怎麼補；上課常規那五條還會標對應哪一條公約與班規
常規沒做到不扣點——像進教室、排隊、收拾這些「怎麼做」的流程，沒做好就重做一次練到會就好。
這也是它跟「班規」分開放兩頁的原因：班規是守不守（會加扣點），常規是熟不熟（練到會）。

🪙 工作做到了怎麼算（一項工作 ＝ 一次，在「🧹 工作分配」分頁）

身上有幾項工作就分開算：同時有打掃和午餐工作，就是兩條線各自結算。

情況會發生什麼崑山幣
當天把自己負責的工作做完、做好工作薪水，週五週結入帳＋2（每次）
有 1～2 次沒做到補做或重做一次，那幾次沒有薪水不扣
有 3 次以上沒做到踩到班規③「打掃要認真」・程度 1−5
做得特別好、被公開表揚亮點・程度 1＋10
🪙 算法只有一種：做幾次領幾次（2026-08-31 起）。打掃、午餐工作每做一次 2 幣——
卡片標題旁的 🪙 標籤就是。原本另外那條「一週 5 次全到 +5」已取消，不必再記兩種算法。
班級常規另計：每天達成 +1 幣、那一週的上課工作天全達成再 +3 幣全勤獎（一般週五天，最多 8 幣）。遇到放假或戶外教學，那天沒有打掃和午餐工作，薪水和常規獎勵就照實際有做的天數算。
這些都在週五週結時一起入帳，存摺才看得到。

沒做到不是先扣錢——先把它補好，這才是「認真負責」真正的意思。 反覆不做才會扣崑山幣，而且扣到 0 就停，不會變負的。

二、要用「座號＋查詢碼」的（個人區）

查詢碼由老師私下發給每位同學（和家長），每個人不一樣，請不要告訴別人。

📊 學習報告（家長）

  1. 班網「學習報告」→ 輸入座號與查詢碼→ 解密開啟。上方分類鈕：📊 學習週報｜✍️ 作文｜📈 學習評量｜🎓 學期總結（2026-11-07 起；下面 2～5 點是「📊 學習週報」）。
  2. 內容：五向度雷達、📚 本週課程重點（全班共同，概覽下方）、各科狀態與建議、亮點、目標、家長協助建議；考試週多一張成績級距圖；有作品的週會顯示「🎨 本週作品」。 等第下方有「📏 等第怎麼看？」可展開，列出四個等第特優／優／甲的標準（2026-09-13 起）。「甲」是基準＝這週穩定、符合期待，不是退步；等第只反映這一週的紀錄，請搭配各科建議與亮點一起看。2026-09-28 起「上課參與／作業成績／生活常規」都改成每天算一個分數、一週五天加起來看等第：天天守好本分＝甲；上課天天主動舉手發表、作業拿甲上或甲上上、主動支援或整理環境，分數就會往優、特優走。遲到、潔牙沒做、打掃沒達標那天只是那一項沒分數，不會因此被打成乙。完整標準見「等第怎麼看？」。
  3. 報告單上方有「📊 學習總覽」（2026-10-16 起）：本週亮點則數、崑山幣存款、內容評量、最新作文四格，五向度各一條逐週小折線（▲▼＝比上週），右邊「最近動態」點「打開 →」直接切到那一期。往回選舊週次，總覽也停在那一週；只在螢幕顯示，列印不會印出。
  4. 「📋 本週課堂作答（知識點）」（2026-10-23 起，那一週上課有用電子白板全班作答才會出現）：孩子這週在課堂上舉卡作答，各知識點答對幾成。⚠＝低於 60%、需要多練習；「資料不足」＝這週那個知識點不到 3 題，先不判斷。沒舉卡也算一題（答對才算對）；請假沒上的題目不算。只看孩子自己，不放全班平均、不排名。
  5. 可按「🖨️ 列印」（一張 A4）或「🕶️ 去識別化」（姓名變 王○明、座號隱藏，適合留存展示；其他內容照常顯示）。

📈 學習評量（2026-11-07 起；原「📈 平時評量」＋「📝 期中評量」合併，期末考也在這裡）

  1. 一樣在「學習報告」裡面——解密後上方分類選「📈 學習評量」（這學期有平時考或期中／期末考才會出現）。
  2. 最上面「🧭 這學期的學習軌跡」每一段都一樣：最上面一句話先講結論（例：「期中考比期中前平時卷：國語、數學進步；社會少 1 分」）；下面國語、數學、社會每科一張圖（2026-11-07 改版），分四欄 ①期中前平時卷 ②期中考 ③期末前平時卷 ④期末考：上半是這一段的分數（○＝平時卷平均、■＝考試）和 ▲▼ 比前一段多或少幾分，下半是這一段每份卷的分數走勢；還沒到的段落是灰色虛線框「🔒 還沒到」，最新那一段標「現在」。
  3. 「📖 選一段來看詳細內容」（2026-11-07 改版）：四個分頁標籤 ①②③④，可以看的寫「👉 點我看」、正在看的寫「👀 正在看」、還沒開始的是 🔒；打開時自動停在最新那一段。切換段落只用這裡的分頁（上面的軌跡圖只用來看）；內容框最上面寫「目前在看」，最下面有「← 上一段／下一段 →」。
  4. ① ③ 平時卷段：三科平時考平均（四捨五入取整數）、考了幾次、最近一次比上一次 ▲▼；③ 多一行「期中前平時卷平均 → 現在」。下面是一句複習建議、🔍 錯題分析、每一次評量的日期與分數（缺考寫「缺考（不計入）」，不算進平均；綜合、健康等其他科列在最後當參考），最後是平時成績怎麼算（課堂表現 20%＋作業 10%＋平時考 20%＝平時 50%，定期評量 50%）。平時考老師登記後下次班網更新就會出現，不必等週五發布。
  5. ② ④ 考試段：三科分數（旁邊是那一段平時卷平均，▲▼ 表示多或少幾分；④ 多一行「期中考 → 期末考」）→「📌 先複習這幾個」→「🔁 平時卷錯過的觀念，考試學會了嗎？」依科目分組（每科寫「N 個知識點，學會 M 個」和進度條，✅ 學會了在前、⚠️ 還要加強在後；那一科沒有低於 80% 的觀念就寫 👍）→ 各科錯題分析（點科目切換）。
  6. 🔍 錯題分析與複習建議（①③ 平時卷段，老師用錯題表登記的平時卷才有）：最上面「📌 先複習這幾個」列出三科所有平時卷裡得分率最低的 3 個知識點（同一個知識點考過好幾次看最近那次），旁邊直接按「👉 複習卡」。下面按科目分頁，每科前面有燈號（🔴 有知識點低於 60%、🟠 最低 60–79%、🟢 全部 80% 以上，看最近一份卷）、最近一份卷的分數與比上一份卷的進退步（▲ 綠／▼ 紅，不同課難度不同當參考），以及「要加強 N 項（比上次多／少幾項）」；同一科最新的卷在最上面且自動展開，較舊的收成一行（卷名、日期、分數、最弱 2 項），按「看詳細 ▾」展開；「要加強」標籤可以直接點開複習卡。每份卷有分數、各知識點得分率（綠 80% 以上、橘 60–79%、紅低於 60%；只畫 80% 以下的，其餘收成「✓ 其他 N 項都在 80% 以上」點開看）， 和最多 5 類「需要加強」的複習建議。建議旁邊和每道錯題旁的「👉 複習卡」可以點，會打開班網「📚 觀念複習卡」那一張：先看重點和例題，再做自我檢查，寫完才打開答案。錯了哪幾題（題號、知識點、扣分）一發布就看得到；正確答案和試卷要等這份卷的開放日才會出現，之前會顯示 🔒。
  7. 只看孩子自己：不放全班平均、不排名。全班級距只在考試那一週的「📊 學習週報」成績摘要裡。

  2. 由上而下：學期總評 → 📈 這學期的評量軌跡（同一組每科軌跡圖＋各科一句話＋「錯過的觀念學會了幾個」與各科 M／N）→ 🗓️ 每週學習足跡（四項等第 × 每一週，加上每週好表現則數）→ 🌱 品格與生活能力：開學初 → 學期末 → 各科學期總評與建議 → 🏅 學期總成績 → 🎨 學期作品牆 → 🌱 學期成長亮點 → 🎯 寒假可以努力的地方（還沒學會的觀念＋複習卡）→ 🤝 家長協助建議 → 🚀 下學期目標。
  3. 🏅 學期總成績＝（期中考＋期末考）÷ 2，四捨五入取整數後換等第：優 90 分以上、甲 80～89、乙 70～79、丙 60～69、丁 未滿 60；只給等第，不放級距、不排名。有一次考試缺考或還沒登記會先顯示「—」，老師確認後再補。

✍️ 作文批改報告（2026-08-02 起）

  1. 一樣在「學習報告」裡面——解密後上方先選分類：「📊 學習週報」是每週報告， 「✍️ 作文」是作文批改報告；再從旁邊選要看哪一週或哪一篇（作文用「✍️ 題目」標示）。
  2. 裡面有：題目、文體、總評等第，以及老師的開場、🔍 抓漏任務、📋 版面格式、 🚀 寫作升級站、🏆 閃亮亮成績單（五個項目的等第與建議）、💬 老師的話， 最後還有一篇 ✨ 修改範文——照著範文比對自己原稿，是進步最快的方法。 報告最後附「📝 作文原文」（電腦辨識的文字）和「📷 原稿照片」，可以對照自己寫的字（去識別化時不顯示照片）。
  3. 有些篇會附 PDF 下載連結，可以印出來夾在作文簿裡。
  4. 老師檢查並勾「發布」之後才會出現；還沒看到就是老師還在批改或還沒發布。

🏦 小小銀行（同學）

  1. 班網「小小銀行」→ 輸入座號與查詢碼→「📖 打開存摺」。
  2. 存摺會顯示目前餘額與最近 30 筆交易（薪水、獎勵金、消費…）。 （「利息」2026-08-14 起停發，以前發過的還是看得到。）
  3. 崑山幣會花掉，XP 不會：XP 記錄你做過多少好事、扛過多少責任， 買東西、被扣點都不會讓它變少。XP 分兩條：
是什麼從哪裡來
🔵 責任 XP把自己的本分做穩幹部週薪、打掃薪水（依次數）、午餐工作（依次數）、班級常規獎勵（每天達成 +1，五天全到再 +3）
🟠 貢獻 XP額外多做的努力正向行為（品格量尺 +1／+2／+3）、亮點（比賽、布可星球）、國數社平均進步獎

兩條加起來就是總 XP，總 XP 決定你的稱號： 🌱 新芽 → ⭐ 小星星（300）→ 🌟 閃耀之星（700）→ 💫 超新星（1200）→ 🏆 星際隊長（1800）。 商店「🛡️ 職務公會」那一層要兩條都到門檻才解得開——只是每天有來、有做完， 還不夠；要有額外的付出才行。 你的 XP 與稱號寫在自己的學習報告裡（只有你和家人看得到，不會公布排名）。

🛒 我要兌換（同學）——用崑山幣換商店的東西

  1. 打開存摺後往下看商店櫥窗：買得起又有庫存的商品會出現「🛒 我要兌換」按鈕。
  2. 錢不夠的商品會顯示「🪙 還差 N 幣」——那就是你的存錢目標！ ⚠️ 已經送出、老師還沒處理的申請會先把錢「預定」起來（2026-09-12 起）： 例如你有 152 幣、已經申請了一張 100 幣的券，那現在可以用的只有 52 幣， 存摺上會寫「其中 🪙 100 幣的申請正在等老師確認，現在可用 🪙 52 幣」， 其他商品的鈕會顯示「還差 N 幣（100 幣已被申請占用）」。 這不是壞掉——是避免你一次申請超過自己的錢、最後有幾項只能被退掉。 「🛡️ 職務公會」和「🧪 創造提案權」還沒解鎖時會顯示「🔒 還差總 XP N／貢獻 XP M」，XP 到了按鈕才會出現。 「🧹 免打掃一次券」這週打掃如果被登記「需改進」，送出時會跟你說下週再來。
  3. 按下「我要兌換」→ 確認 → 送出申請。這時候還不會扣錢，要等老師確認。
  4. 老師核可後才會扣崑山幣（存摺會多一筆「🛍️ 消費」）；如果被駁回，老師會寫原因，錢不會扣。
  5. 小提醒：一次最多 3 筆申請在等老師處理；送出前想一想「這是需要還是想要？」

🎖️ 有些獎勵不用錢，也不能自己換

櫥窗最上面那一區（🌟 今日之星、💌 好消息聯絡簿、🏅 榮譽牆展示、🤝 信任任務）寫著 「🎖️ 老師頒予」——這些不用花崑山幣，但也按不到兌換鈕。 它們是你做到了、老師看見了才會給你的，排在櫥窗第一位，因為它們最珍貴。

🎁 櫥窗最後一區：實物兌換

最下面那一區是拿得到手的東西，只有兩張券： ✏️ 文具兌換券 30（老師手邊的文具任選一件：鉛筆、橡皮擦、便條紙、獎勵貼紙…）、 🍎 食物兌換券 30（營養午餐發剩的水果或乳品、或老師的零食，任選一份）。

為什麼放在最後？ 因為前面四區的東西，是花錢也買不到的：老師當面的讚美、 一整天的特權、一個職務的責任、改變班規的機會。實物你在文具店就買得到， 所以它排在最後——不是不好，是最不特別。

⚠️ 食物券依當天實際有沒有剩，老師會在核可時確認；沒有剩下的時候會退回申請，不會扣你的崑山幣。

🧪 想改班上的規則？創造提案權

櫥窗最下面有一張「🧪 創造提案權」，0 幣，但要總 XP 1200 且貢獻 XP 350（💫 超新星）才換得到—— 比一日班長券（900／250）還高，因為要改規則的人，得先把規則做得很好。 換到之後你可以：提出一條新的常規、班規，或設計一個新的獎勵品項。

怎麼進行（全部在網路上完成）：

  1. 在商店按「🛒 我要兌換」申請 → 等老師核准。
  2. 打開存摺，按「✏️ 我的創造提案」（或到「🎟️ 我的特權」按「✏️ 開始寫提案」），用同一組座號＋查詢碼登入。
  3. 填表一「提案計畫書」：每一格都有提示和例子。可以先按「💾 暫存」，換電腦登入也還在；寫完按「📨 送出計畫書」。 ⚠️ 送出前「🛡️ 護欄自我檢查」五格都要能打勾；送出後就不能改，等老師審核。
  4. 老師通過（貢獻 XP ＋10）→ 照計畫試行，邊做邊記錄 → 同一頁填表二「成果回報單」送出。 老師請你修改或延長時，頁面上會看到老師的意見，改好再送出一次。
  5. 老師確認你做到了（再 ＋20），就會頒給你「🏷️ 命名權」——這張換不到，只能靠做到才拿得到， 你可以幫這條新規則或新獎勵取名字（不能放自己的姓名或座號）。

✋ 寫提案時不要寫同學的名字，照片不拍同學的臉。你的提案只有你、家長（學習報告裡）和老師看得到。

⚠️ 提案有幾件事不能提：牴觸校規的、要花錢買東西的、會增加同學負擔的、 以及「用錢換掉自己該負的責任」的（例如免處罰）。

🎟️ 我的特權（同學）——看看自己有哪些券、還能用幾次

  1. 打開存摺後，存摺下面就是「🎟️ 我的特權」，列出你還能用的券—— 特權券和文具／食物兌換券都會出現（2026-09-07 起）。
  2. 每張券會寫「還可以用 N 次」和兌換日期；用完的券就不會再出現了。
  3. 要使用的時候找老師，老師會在教師專區幫你扣一次（不能自己扣）。
  4. 老師扣完後，這裡的次數要等班網下次更新才會變；以老師那邊的紀錄為準。
  5. 用不完會不會浪費？會的，所以兌換前先想好什麼時候用得到。

🎯 班級共同目標（同學）——全班一起存一個大東西

這一區平常不會出現，老師開了才看得到。
  1. 有些東西一個人存不到（例如全班一起吃的期末夢幻餐點），那就全班一起存。
  2. 想參加就跟老師說「我要捐 N 幣」，老師會幫你記一筆，進度條就往前一格。
  3. 進度條只顯示全班總共存到多少、幾個人一起出力， 不會寫誰捐了多少——捐多捐少都是心意，不需要被比較。 你自己捐了多少，打開存摺就看得到（會是一筆「🛍️ 消費」，事由開頭是「集資」）。
  4. 捐款會扣崑山幣，但 XP 一點都不會少。 你為班上做的事，紀錄永遠留著。
  5. 存滿了進度條會變綠色、跳出「🎉 目標達成」，接下來就等老師實現囉！

🌌 自學星圖（同學）——自己闖關複習，答錯就拿秘笈卡

入口：班網選單「🌌 自學星圖」，或直接打開 https://flyshan2010.github.io/study-orbit/（2026-11-22 起全班開放）。
一律用自己的座號＋自己的查詢碼登入，進度才會記在你的名下、上排行榜。登入後畫面上會寫「N 號」（你的座號）；如果寫的是「體驗 N 號」，代表用到上課試玩的帳號，請登出再用自己的查詢碼登入。
  1. 登入：打開自學星圖 → 中間的「🏯 皇城」→「登入」→ 輸入座號與查詢碼（和學習報告同一組）。 沒登入也能玩，但畫面上會寫「試玩中，不會記錄」：進度不會存，也不會上排行榜。
  2. 找關卡：皇城在中間，四周是各科的區；點區 → 點小島（單元）→ 點關卡 →「▶ 進入這一關」。 插紅旗的島＝期中考過的範圍，可以拿來複習。
  3. 一關 7 題：先選答案再按「確認答案」，答對後按「下一題」。上方 7 盞燈記錄你每一題：
燈什麼時候亮
🟡 金燈第一次就答對（但不到 2 秒就按答對的只算銀燈，請先看完題目）
⚪ 銀燈用了「查看提示」或看過秘笈卡之後才答對
不亮同一題兩次都錯（看完詳解再往下）
  1. 答錯不扣分：只會讓連對歸零。系統會依你選的答案發一張秘笈卡（正確的想法、例子、檢查口訣），再出一題同類的讓你試；答對就蓋「已克服」章，7 天後會再考你一次。秘笈卡都收在皇城的「複習卡冊」。
  2. 星等：7 盞全亮而且金燈至少 6 盞＝⭐⭐⭐；亮 5 盞以上＝⭐⭐；亮 3 盞以上＝⭐。重玩只記最高的那次。 過關可以翻一張故事卡；一座島每一關都 7 盞金燈，就能打開那座島的寶箱。
  3. 今日任務（每天 3 件）：①複習（複習卡冊裡今天到期的卡做一張；沒有到期的，就把沒到 3 星的關再玩一次）②前進（下一個還沒過的關）③自選（任選一關）。一回合只算一件，做完會顯示「3／3 完成！」。 連續自學天數＝連續幾天至少玩完一回合；週六、週日和停課日沒玩不會中斷。
  4. 排行榜：可以看總排行和各科，比星數、進度（過了幾關）、本週星數。只列前 5 名和你自己、只顯示座號；成績只算自學星圖的練習，不是考試成績。
  5. 換一台平板接著玩：在另一台用同一個座號登入，那一關會出現「繼續上次（第 N 題）」。 畫面上方寫「待上傳 N 筆」＝作答還在送；換台或登出前等它不見再走。按登出時如果還有沒送出的，會先問你。
  6. 出現「登入過期了，請重新登入」：老師換過查詢碼或登入太久，用（新的）查詢碼再登入一次就好，還沒上傳的作答會留著。
  7. 登不進去：先確認座號和查詢碼都打對（查詢碼和看學習報告的一樣）；畫面寫「嘗試太多次」就等一分鐘再試；還是不行請告訴老師，不要借同學的查詢碼登入。

三、注意事項

  • 🔒 查詢碼＝你的個人鑰匙，不要外流；忘記了請找老師。
  • 存摺與報告內容只給自己和家長看，請勿轉傳截圖。
  • 頁面資料每天自動更新三次；老師處理完兌換後也會手動更新，稍等一下再重新整理即可。
